# Companies Act 2013 documents

PDF documents used by the Companies Act 2013 application.

- `documents/`: 1,004 original PDFs, with their filenames and contents preserved.
- `manifest.json`: document paths, download URLs, byte sizes and SHA-256 checksums.
- `documents-index.csv`: the same document list in an Excel-compatible format.

Total document size: 1,066,399,680 bytes (about 1,017 MiB).

Each document is stored once. The manifest can be used to verify downloaded files and reuse a saved copy when a document is opened again.

This repository stores documents only. Uploading these files does not change the application or enable offline downloading by itself.
